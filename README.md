# 🪙 Heads or Tails

A simple Python coin flip game that randomly chooses between **Heads** and **Tails**.

## 🎮 How It Works

The program uses Python's `random` module to randomly generate either:

* 🪙 Heads
* 🪙 Tails

Every time you run the program, the result can be different.

## 🛠️ Built With

* 🐍 Python
* `random.randint()`
* `if / else`
* Variables
* Conditional statements

## 📌 Example

```text
Heads
```

or

```text
Tails
```
